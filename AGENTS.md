# Agent instructions

Skills for this repository are centralized in [SkillMesh](https://github.com/lreyesm1999/SkillMesh) (preset `nextjs`, skills: architecture, frontend, testing, security, documentation). Read `.agents/skills/<skill>/SKILL.md` for the rules and `.skillmesh/project-context.md` for this project's specific facts (stack, build quirks, deployment). Do not edit files under `.agents/skills/` directly — they are hash-verified by `skillmesh.lock.json`; use an override in `.skillmesh/overrides/<skill>.md` for a documented, dated exception instead.
