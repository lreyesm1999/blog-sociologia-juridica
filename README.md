# Sociedad y Derecho

Blog académico sobre sociología jurídica — proyecto final del curso, desarrollado con Next.js (App Router) y TypeScript.

**Autor:** Lenier Reyes Morales

## Contenido

Seis entradas que analizan la relación entre la sociedad, el derecho y el individuo: qué estudia la sociología jurídica, la relación entre sociedad y derecho, los distintos órdenes normativos, las funciones del derecho (bien común, justicia, seguridad jurídica), la libertad individual y la eficacia del derecho como herramienta de transformación social.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción (usa el compilador webpack de Next.js)
- `npm run start` — sirve el build de producción
- `npm run lint` — ESLint

## Despliegue

Proyecto pensado para desplegarse en Netlify (framework Next.js autodetectado, `npm run build` como build command).
